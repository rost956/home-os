# Технический долг

Эти пункты не блокируют текущий домашний production-релиз и не должны смешиваться с исправлениями стабильности.

## Высокий приоритет

- Добавить серверную пагинацию старой истории чата. Офлайн-синхронизация уже догружает страницы, но первое открытие длинного диалога пока формирует всю историю целиком.
- Вынести оставшиеся предметные области из `app/main.py` в отдельные routers/services и подключить версионируемые миграции схемы (например, Alembic) до перехода с домашнего SQLite на более крупную установку.
- Перенести inline JavaScript и CSS из шаблонов в статические файлы, после чего убрать `'unsafe-inline'` из CSP.

## Средний приоритет

- Расширить автоматизированные проверки WebSocket: origin, повторное подключение, большие очереди сообщений и несколько одновременных клиентов.
- Добавить browser regression suite для ключевых desktop/mobile маршрутов и хранить эталонные скриншоты в CI artifacts.
- При переходе на несколько web workers вынести rate limiting и фоновые задания в общий backend; текущая конфигурация намеренно использует один worker.
- Регулярно проверять восстановление полного backup на отдельной тестовой машине, а не только unit-тестом архива.
